# Dima plotting

Legacy plotting scripts (`plot_main.py` and the notebooks) that predate
[pyfesom2](../pyfesom2). They are kept for reference only.

The PHC3.0 annual climatology that `plot_main.py` compares against
(`phc3/phc3.0_annual.nc`, ~33 MB) is no longer shipped in the repository.
To use these scripts, place a copy of the file in `visualization/view/phc3/`,
e.g. from the FESOM input pool (`/pool/data/AWICM/FESOM2/INITIAL/phc3.0/` on
DKRZ Levante) or from the FESOM data server.
